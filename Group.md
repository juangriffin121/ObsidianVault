A group is a set of mathematical objects together with an operation between two elements that is closed (a○b in G if a in G and b in G)
The operation should have this properties:
- asociativity: (a ○ b) ○ c = a ○ (b ○ c)
- has identity: a ○ I = a
- every element has an inverse also in G: a○a_inv = I

A lot of times groups appear when studying symmetries, where operations that preserve some quantity of a base object can be coupled together to create another operation (rotations...)

From [[quantum mechanics]] to [[differential geometry]]  ([[Lie groups]]) and even [[Cryptography]] ([[cyclic groups|cyclic group]]) groups are a fundamental concept.
