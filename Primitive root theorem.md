
For a finite field of prime order p $F_p$ there always exist an element g $\in F_p$  that has the following property:
$$F_p^* = \{1, g^1, g^2 ...g^{p-2}\}$$
$F_p^*$ is all non zero elements of $F_p$

elements like g are called generators or primitive roots

There are actually $\phi(p-1)$ primitive roots for $F_p$
where $\phi$ is euler's totient function that calculates the number of coprimes of a number
